这是一个连锁采集mod
# 功能介绍
- ## 形状支持
  - 支持三种形状
    - 不定型
    - 线性（可支持调参）
    - 整区块（同样支持调参）
- ## 配置
  - 支持个人配置和服务器配置两种种类，可通过simpleminer config individual/server打开GUI界面
- ## 性能
  - 本mod目前主要注重性能部分，本人CPU i3-12100f测试下可做到40000方块无卡顿
  - 后续可能会有其他优化。~~虽然我现在懒得做就是了（~~
- ## 兼容性
  - 本mod也为兼容性需求提供了一些配置文件
